# React Utils
Components, utilities and other things to use with ReactJS

## Promise Renderer
An reactive and much cleaner approach to handle all promisse states based o flutter FutureBuilder.

## Functions
several little functions used to speedup some process

## Hooks
- ### useLazyCachingValue
A hook to lazy computed its value when first called and caches its results. It accepts both sync and async functions.

## Other
- ### InfiniteScroll
Implements the InfinieScroll approach, accepting a callback for calling every time user reach end of scroll
- ### ExpandableText
A text component that uses mui for typography styling, css manipulation and shrinks text appending '...' at the end by [max lines], with a smooth animation and flexible height
- ### NormalizedWidthContainer
A container (mui) that is flexible, centering its contens if screen is wider than max size.
